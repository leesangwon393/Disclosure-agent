## 1. 채점 방법론 — 정직하게 밝힙니다

이 리포트의 숫자는 **3번의 자동채점기 수정을 거친 결과**입니다. 처음 단순 문자열매칭으로 돌렸을 때 compare 유형이 59/60 FAIL로 나왔는데, 실제 답변을 읽어보니 전부 정답이었습니다(gold 정답이 `"효성중공업 (HD현대일렉트릭 258,000,000,000 vs 효성중공업 787,063,743,500)"`처럼 압축된 형식이라 단순매칭이 실패). 같은 이유로 역질문(ambiguous)·거부(abstain) 유형도 문구 패턴을 더 잡아야 했습니다. 이 수정들 덕분에 채점 정확도가 크게 올랐지만, **REVIEW 123건(summary/funding/correction 전체 + 일부 복합추론)은 여전히 자동판정이 불가능해서 사람이 직접 읽어야 합니다.** CSV에 전체 답변 원문이 있습니다.

## 3. 남은 약점 두 가지

### 🟡 3-1. lookup_periodic — 50%, 유일하게 절반을 못 넘김

README가 이전부터 "정기공시가 48%"라고 적어뒀던 바로 그 문제이고, v2를 켜도 그대로입니다. 실패 사례:

```
Q: SK텔레콤의 분기보고서 (2023.03)에 기재된 리스부채는 얼마인가?
gold: (6,503)
A: 383,890백만 원 (다른 표/다른 항목 값을 가져옴)

Q: 기아의 분기보고서 (2024.03)에 기재된 IV.이사의경영진단및분석의견은 얼마인가?
A: "분ㆍ반기보고서엔 이 항목을 기재하지 않는다"고 정확히 설명 
   → 맞는 답인데 숫자가 없어서 자동채점상 FAIL 처리됨(채점기 한계)
```
문서당 청크가 900~1,300개인 사업보고서/분기보고서 안에서 **정확한 표를 못 집는** 문제로, 원인이 이미 README에 진단돼 있습니다(`facts` 추출이 요약재무정보 섹션을 못 뽑음). 이번 494문항으로도 재확인됐습니다.

### 🟡 3-2. compare — 75%, 대부분 "버전 선택 오류"

```
Q: SK텔레콤과 KB금융 중... 순자산액이 더 큰 기업은?
gold: KB금융 (... 25,042,075,532,026)
A: KB금융의 순자산액 24,988,557,604,121원 (다른 공시일자 값을 씀)
```
숫자 자체는 근거에 실제로 있는 값인데, **여러 시점의 공시 중 정답 셋이 기대하는 버전과 다른 걸 골랐습니다.** 완전히 틀린 게 아니라 "어느 시점 값이 맞는 답인지"의 모호성에 가깝습니다.

### 🔴 3-3. 역행 1건 — 정정공시(`[기재정정]`) 처리에서 v2가 오히려 후퇴

```
Q: 한화에어로스페이스의 2025년 05월 [기재정정]주요사항보고서(유상증자결정)에 기재된 1주당액면가액은?
gold: 5,000
Before(구경로): 5,000원 — 정답
After(v2):     "필수 항목([기재정정]주요사항보고서)을 공시 근거에서 확인할 수 없어 답변하지 않습니다" — 오답
```
100문항 중 유일한 역행 사례입니다. 서버 기동 로그에 찍혔던 `[CORRECTION] doc_id=... 원본/직전정정본 미발견` 경고와 같은 계열의 문제로 보입니다 — 정정공시 체인이 제대로 안 엮여서 v2의 필수항목 검증이 오작동한 것 같습니다. 표본이 1건이라 확대해석은 금물이지만, 정정공시(`[기재정정]`) 관련 질문만 추가로 몇 개 더 테스트해볼 가치는 있습니다.
